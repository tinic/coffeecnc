# Bundled interface fonts

DM Sans (variable weights 400–700) and IBM Plex Mono (400, 500), Latin WOFF2 subsets downloaded from the Google Fonts CSS API on 14 November 2026. Source families: [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans) and [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).

Both use the SIL Open Font License 1.1. The original license notices are included in `dmsans-OFL.txt` and `ibmplexmono-OFL.txt`. Font files are served locally; the panel does not request them from the internet.
